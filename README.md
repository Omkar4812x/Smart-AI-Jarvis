# 🤖 Smart AI Jarvis

> **Lightweight Python desktop virtual assistant for rapid voice command processing and system automation.**

---

## ✨ Features

- 🎙️ **Continuous Listening Engine** (`voice_manager.py`)
  - Real-time speech recognition with auto noise cancellation.
- ⚡ **Automation Command Dispatcher** (`automation.py`)
  - Launches desktop applications, executes system shortcuts, and performs web searches.
- 🧠 **Memory & Prompt Extension** (`memory.py`, `prompts.py`)
  - Session history and prompt templates for customizable assistant personas.

---

## 🛠️ Tech Stack

- **Language**: Python 3.10+
- **Speech**: `SpeechRecognition`, `pyttsx3`, `PyAudio`
- **Automation**: `pyautogui`, `psutil`

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Omkar4812x/Smart-AI-Jarvis.git
   cd Smart-AI-Jarvis
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run Smart AI Jarvis**:
   ```bash
   python main.py
   ```
